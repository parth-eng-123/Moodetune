MOTUNE STREAMLIT DEPLOYMENT

1. Upload/replace app.py and requirements.txt in the GitHub repository root.
2. Do NOT rely on runtime.txt to change the Community Cloud Python version.
3. In Streamlit Community Cloud, create a new deployment (or delete the old app and redeploy).
4. Open Advanced settings and select Python 3.11.
5. Deploy.

IMPORTANT: The existing deployment used Python 3.14.7 and DeepFace could not resolve TensorFlow there.
Python 3.11 must be selected in Streamlit's Advanced settings.
